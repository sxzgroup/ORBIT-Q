# Methods and provenance

The reported cohort is the original 12-task round.

Base: `2187118fecc0e275efc0763c676baa8e2df57108`. Each solve used the canonical task and TensorCircuit prompt in a fresh Harbor container, with no prior model trajectory. The solver and separate verifier used the same image (see [protocol](execution-protocol.json)), with 6 CPUs and 10 GiB. Agent network access was enabled. Functional checks, static policy and the independent GPT-6 Astra high source audit determine reward; artifact speed is not a reward multiplier. There is no human adjudication in this campaign.

Solver wall time is the agent execution interval, not end-to-end job time. Every selected task contributes to total time, tokens and recorded cost, including failures. No missing cost was backfilled. Per-pass metrics divide by the number of passes. In resource panel (c) the bubble **area** represents total solver cost.

Runtime replay uses the unchanged canonical evaluator and expert implementation at the base commit. One cold process per selected implementation ran serially on the same Mac/Colima backend, with 6 CPUs, 10 GiB, networking off, OMP=6 and BLAS=1. Tasks 01 and 12 share the same frozen input fixture between implementations. The clock is the evaluator's `run_solution` timer. The same measured expert time is used across variants. Invalid submissions are not timed. Measured-only geometric means use functional passes with matching effective-config hashes and positive times on both sides. Following the historical reviewer adjustment, the published time-ratio figure and table also include the 50 s estimated reference for Task 08 when a valid artifact has a measured time; the original OOM and the measured-only result are retained.

The replay container has a 1,200-second wall-clock safety cutoff. This is distinct from both the original Harbor trial and the evaluator's artifact timer; replay outcomes never overwrite official rewards. The original submitted files are unmodified. If a Task 04 export redacted `true_p01` and `true_p10`, only the replay copy restores those two field names; its digest and the export digest are recorded separately. Source, evaluator, fixture and replay hashes are in [timing evidence](timing-evidence.json).

Historical outcomes/resources are from [the earlier benchmark archive](https://github.com/QingyunQian/ORBIT-Q/tree/7c0711370b528401fb9bc704fc30826a67a89bab/results/gpt6astra-high), using its published final outcomes. The old Sol entries can include human adjudication. Historical runtime points retain the [paper figure's inputs](https://github.com/QingyunQian/ORBIT-Q/tree/a3dd63a6d0eab02ae79abcc7a1723ffeda9b2611/paper/source_data), including the previously published adjusted reference for the historical GPT-6 Astra point. These are descriptive comparisons, not controlled cross-generation or reasoning-effort experiments.

The frozen comparison tables retain the historical results. Retired configurations are filtered only when drawing the comparison figures.

To redraw, run `python render_figures.py` here (Python 3, NumPy and Matplotlib). The renderer reads only the included JSON and writes five PNG/SVG/PDF figures. To replay a pair, use e.g. `python replay_task.py 04 --repo /path/to/ORBIT-Q --context colima` with the recorded image already loaded. To validate the distributed files without running a solver, run `python verify_package.py`. Raw Codex sessions and host credentials are not distributed.
