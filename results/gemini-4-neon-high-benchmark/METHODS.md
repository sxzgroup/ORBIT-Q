# Methods and provenance

The reported cohort is the complete 12-task round for `gemini-4-neon-high` (`high` effort) executed in **Antigravity** (`antigravity-cli 1.5.17`) and audited uniformly in **Antigravity** by `gemini-4-neon-high` (`high` effort).

Base: `2187118fecc0e275efc0763c676baa8e2df57108`. Each solve used the canonical task and TensorCircuit prompt in a fresh Harbor container, with no prior model trajectory. The solver and separate verifier used the same image `orbitq-tc18-agy:1.5.17` (`antigravity-cli 1.5.17`, see [protocol](execution-protocol.json)), with 6 CPUs and 10 GiB. Agent network access was enabled. Functional checks, static policy and the independent Gemini 4 Neon high source audit determine reward; artifact speed is not a reward multiplier. There is no human adjudication in this campaign.

Solver active time is the awake-only CLI execution interval measured with `macOS CLOCK_UPTIME_RAW` (excluding system sleep), not end-to-end Harbor job time. Every task contributes to total time, tokens and recorded cost, including 1,800 s timeouts. Token-only Standard Gemini Developer API-equivalent cost is computed at frozen 2026-11-25 list rates (`uncached_input=$3.00/1M`, `cache_read=$0.15/1M`, `output_including_thinking=$15.00/1M`; SHA-256 `283ebf5d8547c27f76556bd933e6a9623b0ed15ea896bbe5b9a790b936a194b8`), excluding verifier resources. For timed-out trials without a terminal `result` event, usage is summed from all completed `step_update` records in the raw stream (verified to match terminal `result.usage` identically on completed trials). Per-pass metrics divide by the number of passes. In resource panel (c) the bubble **area** represents total API-equivalent solver cost.

Runtime replay uses the unchanged canonical evaluator and expert implementation at the base commit. One cold process per selected implementation ran serially on the same Mac/Colima backend, with 6 CPUs, 10 GiB, networking off, OMP=6 and BLAS=1. Tasks 01 and 12 share the same frozen input fixture between implementations. The clock is the evaluator's `run_solution` timer. The same measured expert time is used across variants. Invalid submissions are not timed. Measured-only geometric means use functional passes with matching effective-config hashes and positive times on both sides. Following the historical reviewer adjustment, the published time-ratio figure and table also include the 50 s estimated reference for Task 08 when a valid artifact has a measured time; the original OOM and the measured-only result are retained.

The replay container has a 1,200-second wall-clock safety cutoff. This is distinct from both the original Harbor trial and the evaluator's artifact timer; replay outcomes never overwrite official rewards. The original submitted files are unmodified. Source, evaluator, fixture and replay hashes are in [timing evidence](timing-evidence.json).

Historical outcomes/resources are from [the earlier benchmark archive](https://github.com/QingyunQian/ORBIT-Q/tree/7c0711370b528401fb9bc704fc30826a67a89bab/results/gpt6astra-high), using its published final outcomes, combined with the v2 GPT-6.2/6.1 results from PRs #30–#32 (`a7383e3`). The old Sol entries can include human adjudication. Historical runtime points retain the [paper figure's inputs](https://github.com/QingyunQian/ORBIT-Q/tree/a3dd63a6d0eab02ae79abcc7a1723ffeda9b2611/paper/source_data), including the previously published adjusted reference for the historical GPT-6 Astra point. These are descriptive comparisons, not controlled cross-generation or reasoning-effort experiments.

The frozen comparison tables retain the historical results. Retired configurations are filtered only when drawing the comparison figures.

To redraw, run `python render_figures.py` here (Python 3, NumPy and Matplotlib). The renderer reads only the included JSON and writes five PNG/SVG/PDF figures. To replay a pair, use e.g. `python replay_task.py 04 --repo /path/to/ORBIT-Q --context colima` with the recorded image already loaded. To validate the distributed files without running a solver, run `python verify_package.py`. Raw agent streams and host credentials are not distributed.
